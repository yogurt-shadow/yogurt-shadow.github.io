# 一切的开始...为什么要整一个 Blog 😎

时间戳先标一笔：之前的发布时间是 2025/09/28（测试用），现在是 2025/10/09。想了很久，还是想把自己的碎碎念、灵光乍现和成长路上的小情绪，都留在一个能长期栖身的地方。于是，这个 Blog 就诞生啦！(๑•̀ᄇ•́)و✧

## Why Blog on WebPage?

发过不少平台，最后还是决定自留地最香：
1. 知乎：更多偏技术硬核，我想写的有时候很主观，很“我”。
2. 小红书：emmm…节奏太快，情绪太满，容易被流量裹挟（而我只想安静当个记录者 (｡•́︿•̀｡)）。
3. 飞书/语雀：更像工作区，发多了像在交周报，太严肃啦。
4. 日记 App：可以，但数据存储让我不踏实，小厂说没就没，回忆也跟着蒸发，想想就心慌 ( ; _ ; )/~~

那就自己搭！不想和个人主页打架，就在 webpage 的 blog 入口挂了个 Hexo，小伙伴 Cursor 也来帮忙干活（我负责下命令和挑主题，分工明确嘿嘿）。

## Future?

这里会写：心态起伏、学习拐点、超勇敢的瞬间、也包括那些想躲起来的时刻。成长之所以动人，是因为很多感受都是“当下限定”的：
- 跌倒的一瞬间的自嘲与倔强；
- 亲人离开的那个夜晚，世界突然变得安静；
- 论文推进的深夜和咖啡；
- 收到 dream school offer 的那一周，想要和全世界击掌！(ง •̀_•́)ง

很多日子会远去，但当时那个“傻乎乎、却很真的自己”，值得被留下。等以后回头看看，会觉得：啊，这就是我走过的路呀。✨

如果你也刚好路过，希望这些文字能给你一点点陪伴；如果你正卡在迷雾里，别怕，我们慢慢走。🌟

最后小声说一句：本博客有不少帖子由 Cursor 帮我润色，风格会尽量保持统一哒～(＾▽＾)／
